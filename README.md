# No Inventory Facility

**No Inventory Facility (NIF)** is a Minecraft mod built around a simple idea:

> **What if you didn't have an inventory at all?**

NIF replaces the traditional inventory and hotbar with a custom two-hand item system.

## Features

* Custom main-hand and offhand item system
* Two-handed item support
* Custom item pickup
* Server-side pickup validation
* Custom HUD for items, health, hunger and experience
* Vanilla inventory screen and hotbar removed

## Status

**0.2.0-beta**

NIF is in early public beta. The core systems are functional, but the HUD, animations and some vanilla interactions are still being refined.
